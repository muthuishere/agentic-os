**A computer-use MCP server that is also a CLI a person can type.** 96 commands
across 34 groups: windows, input, screen capture, files, processes, packages,
network, audio, clipboard, services, messaging.

## One surface, two callers

Every command is an MCP tool, and every MCP tool runs the identical code path
you get at a prompt. There is no second implementation behind the protocol — a
tool call resolves the same route and invokes the same `Runner` the terminal
does.

```sh
agentic-os window move Chrome --zone=1B     # you, at a terminal
```

```json
{ "name": "window_move", "arguments": { "app": "Chrome", "zone": "1B" } }
```

Those two lines are the same work. What you test by hand is what the agent gets,
and a bug you reproduce in a shell is the bug the agent hit.

## Three platforms, verified

macOS, Windows and Linux — all three tested by a suite that drives the built
binaries on real machines, locally, over SSH and through an agentbus node,
including a headless Linux server. The macOS window backend is CoreGraphics
through cgo; Windows is Win32; Linux is wmctrl and xdotool.

## Safety as structure

The refusals are part of the design, not a disclaimer in a README.

- Commands that need a screen are refused with a reason instead of failing deep
  inside a display-server call.
- `file delete` will not touch a filesystem root, `$HOME`, or a system
  directory.
- `serve` binds loopback.
- Services are namespaced `agentic-os.<name>`, so removing one cannot reach a
  system service.
- Telemetry records how many arguments a command got, never what they were.

```console
$ agentic-os file delete /
agentic-os: refusing to delete /
$ agentic-os file delete $HOME
agentic-os: refusing to delete /Users/muthuishere
```

The [safety model](/agentic-os/safety/) page has the rest.

## One verb set that means the same thing everywhere

```sh
agentic-os pkg install ripgrep    # brew · winget · scoop · choco · apt · pacman · yay · dnf
agentic-os window move Chrome --zone=1B
agentic-os capture screenshot --app=Chrome --out=/tmp/shot.png
```

`--app=Chrome` matches the same window on all three platforms. That took fixing
Windows and working around Linux to make true, which is the sort of work a
single verb set is for.

## Extensible without forking

A JSON file in `~/.config/agentic-os/adapters/` adds a group. An executable
named `agentic-os-<group>-<name>` on `PATH` adds a command. Both become MCP
tools on exactly the same terms as a built-in — and neither can shadow one. See
[extending it](/agentic-os/extending/).

## Where the shape came from

The command *shape* — `<group> <command>` routes resolved by longest prefix,
discoverable help, a machine-readable index, drop-in plugins — is borrowed from
the [omarchy CLI](https://learn.omacom.io/2/the-omarchy-manual/115/omarchy-cli).
The implementation is Go, on three platforms. Everything outside that
map — `window`, `mouse`, `key`, `exec`, `file`, `msg`, `serve` — is new here:
the parts an agent needs that a desktop CLI never had.
